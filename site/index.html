Your own link shortener. Free to run. Yours to keep.

Waymark is an open-source alternative to hosted services like Short.io: short links on your own domain with country and device routing, QR codes, analytics, a team and an API. It runs free on Cloudflare or on any server.

One link, many routes.

In Waymark a short link is a signpost with rules. Each visitor lands where it makes sense for them, and you see which route was taken how often.

Everything a link shortener needs. Under your control.

Waymark is private: nobody can sign up on their own. The owner invites the team and hands out API keys with exactly the permissions they need.

Links

  • Custom or random slugs, with paths and Unicode
  • Any number of branded domains
  • Tags, notes, archive, bulk actions
  • 301, 302, 307 or 308 redirects, cloaking

Routing

  • Rules by country, device, OS, language
  • A/B tests with weights
  • UTM builder and query pass-through
  • Start, expiry, click limit, password

Analytics

  • Clicks and unique visitors over time
  • Countries, cities, referrers, devices, browsers, languages
  • QR scans counted apart, bots filtered out
  • No IP addresses stored

Team & security

  • Owner, admin, editor and viewer roles
  • Invite-only, no public sign-up
  • Audit log of every change
  • Throttled sign-in, strict CSP

API & webhooks

  • Everything the app does, over HTTP
  • Keys with scopes, domains and expiry
  • Signed webhooks on changes and clicks
  • Optional public shortening, rate-limited

Import & export

  • Direct import from Short.io
  • CSV from Bitly, YOURLS, Kutt, Rebrandly, Dub
  • Full backup as JSON
  • Self-updating copies of the repository

Move from Short.io and keep your links.

Waymark reads your links straight from the Short.io API: destinations, slugs, tags, expiry, iOS and Android targets, UTM values. The API does not return passwords or geo rules; set those again afterwards.

  1. Add the domain

    Enter your old short domain under Domains.

  2. Import

    Paste a Short.io API key, pick the domain, start.

  3. Check

    Test a few links on the Waymark hostname.

  4. Switch DNS

    Point the domain at Waymark. Imported links keep working at the same address.
